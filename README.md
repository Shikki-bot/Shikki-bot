## 🌊 The Shikki Flow

*How a sentence becomes shipped code.*

| | Step | What happens |
|:--:|---|---|
| **01** | **Describe** | Give Shikki a task in natural language. It breaks it into a plan with a role for each agent. |
| **02** | **Dispatch** | Agents receive assignments over the **NATS mesh** — each in an isolated workspace with scoped context. |
| **03** | **Deliver** | Results are merged, reviewed, and presented. You approve, iterate, or ship — always in control. |

## ⚙️ Built for developers who own their stack

| | | |
|---|---|---|
| ◆ **Multi-Agent Dispatch** — planner, coder, reviewer, each with dedicated context | ◇ **NATS Mesh** — sub-millisecond agent comms, local or distributed, no cloud relay | ◢ **TUI Dashboard** — real-time terminal, watch agents work and intervene |
